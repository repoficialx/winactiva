# winactiva ![Static Badge](https://img.shields.io/badge/status-activo-brightgreen) ![Static Badge](https://img.shields.io/badge/activaci%C3%B3n-legal-blue) ![Static Badge](https://img.shields.io/badge/plataforma-Windows-lightgrey)

**winactiva** es una herramienta que permite **activar legalmente Windows** utilizando las claves públicas (GVLK) proporcionadas por Microsoft en su documentación oficial.

Este proyecto está diseñado para simplificar la activación de sistemas Windows en entornos de prueba, educativos, o de evaluación técnica.

---

## ¿Cómo funciona?

- Utiliza claves GVLK públicas (no piratería)
- Configura automáticamente el **KMS Client Setup Key**
- Ejecuta comandos para activar la licencia con los servidores de Microsoft

---

## ¿Es legal?

**Sí.**  
Las claves GVLK (Generic Volume License Keys) que utiliza esta herramienta:
- Son proporcionadas por Microsoft para entornos empresariales y educativos
- No violan ninguna ley ni política si se usan con fines educativos o de prueba

**Este proyecto no incluye ni promueve activadores ilegales, cracks o licencias robadas.**

---

## Requisitos

- Windows
- Conexión a internet (para contactar con los servidores KMS públicos)

---

## Cómo se usa

1. Ejecuta la aplicación como administrador
2. Selecciona la edición de Windows instalada
3. Haz clic en “Activar”
4. ¡Listo!

También puedes ver los comandos utilizados para aprender o personalizar el proceso.
